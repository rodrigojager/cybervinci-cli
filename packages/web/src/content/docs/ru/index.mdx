CYBERVINCI is a compatibility fork of OpenCode focused on preventing indefinite hangs in provider streams, MCP calls, tool finalization, and cleanup.

## Build and install

This source tree does not claim a public package-manager feed, hosted installer, social account, or release repository. Build the reviewed source locally and install the resulting binary:

```bash
bun install
bun run --cwd packages/cybervinci script/build.ts --single --skip-install --skip-embed-web-ui
./install --binary /path/to/cybervinci
```

The executable, config directory, package scopes, and product UI use the CYBERVINCI name. Official OpenCode service names, provider IDs, headers, and API keys remain unchanged only where compatibility requires them.

Updates are disabled by default. External update and publishing targets must be configured explicitly by the operator.
