title: OpenCode Zen compatibility
description: Using the official OpenCode Zen service from CYBERVINCI.
---

CYBERVINCI is compatible with the official **OpenCode Zen** provider. OpenCode Zen is operated by the OpenCode project; CYBERVINCI did not create it, does not own it, and does not sell or administer the service.

Zen is optional. CYBERVINCI can also use other supported providers.

## Connect

1. Sign in to the official [OpenCode Console](https://opencode.ai/auth) and obtain an OpenCode Zen API key.
2. Run `/connect` in the CYBERVINCI TUI.
3. Select **OpenCode Zen** and enter the key.
4. Run `/models` to load the models currently exposed by the service.

Compatibility identifiers intentionally remain unchanged:

- Provider ID: `opencode`
- API key environment variable: `OPENCODE_API_KEY`
- API base: `https://opencode.ai/zen/v1`
- Models endpoint: `https://opencode.ai/zen/v1/models`

A model reference therefore uses `opencode/<model-id>`.

## Service terms

Models, prices, limits, retention rules, and regional availability are controlled by the official OpenCode Zen service and may change independently of this fork. Verify the current details in the official OpenCode Console before sending sensitive data or enabling billing.

CYBERVINCI only provides the client-side compatibility path. Questions about the hosted service belong to its official operator; questions about this fork or a local build belong to the maintainer who supplied the distribution.
