---
title: Quickstart
description: Build and run CYBERVINCI from reviewed source.
---

From the repository root:

```bash
bun install
bun run --cwd packages/cybervinci script/build.ts --single --skip-install --skip-embed-web-ui
```

Install a reviewed binary:

```bash
./install --binary /path/to/cybervinci
```

Configuration is stored under `~/.config/cybervinci`. Updates are disabled unless the operator explicitly configures trusted external targets.
